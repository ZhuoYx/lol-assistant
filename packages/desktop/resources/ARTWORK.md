# 角色背景与应用图标

制作方式：内置 imagegen。所有最终素材均已保存在仓库。

- `src/renderer/src/assets/backgrounds/jinx-lux-anime.webp`：金克丝、拉克丝，二次元动漫星空。
- `src/renderer/src/assets/backgrounds/yasuo-yone-ink.webp`：亚索、永恩，国风水墨。
- `src/renderer/src/assets/backgrounds/teemo-lulu-fantasy.webp`：提莫、露露，半厚涂奇幻森林。
- 同目录 PNG 为原始生成图片；WebP 为界面使用的压缩副本，每张约 300 KB。
- `resources/icons/poro-companion.png`：透明底卡通魄罗原图。
- `resources/icons/poro-companion.ico`：16/24/32/48/64/128/256 尺寸 Windows 图标。
- `src/renderer/src/assets/poro-companion.png`：用于侧栏、网页图标的小尺寸副本。

背景可在设置页选择，浅色/深色模式使用不同遮罩和玻璃卡片色。

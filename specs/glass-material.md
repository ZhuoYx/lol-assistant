# 半透明磨砂玻璃材质

2026-10-30 更新。

## 统一材质

- 主面板、玩家卡片、推荐卡片、背景选择卡片及状态面板共用 `.card` / `.glass-panel` / `.glass-surface`。
- 默认卡片透明度为 **60%**，背景底色不透明度为 0.4；文字、图标保持完整显示。
- 默认背景模糊为 **28px**，搭配饱和度增强、斜向柔光、亮边、底边阴影和细颗粒纹理。
- `assets/glass-grain.svg` 使用固定种子的平铺纹理，经过构建内联并缓存，不持续生成噪点。
- 嵌套面板使用更轻的底色和 12px 模糊，避免两层底色叠加后看起来接近不透明。
- 战绩等信息密集的面板略微提高底色密度，仍然保留背景透色与纹理。
- 原先会清空纹理层的 `background` 颜色覆盖改为 `background-color`，选中和悬停状态继续保留玻璃材质。

## 用户调节

设置 → 外观中提供：

- **卡片透明度**：20%–75%。数值越高，背景越明显。
- **磨砂强度**：12–48px。数值越高，背景越柔和。

两项即时应用于各模块并保存在本机；浅色、深色、跟随系统均可使用。

已通过界面键盘操作调整透明度与磨砂强度，并验证刷新后的保存结果。构建、Web 类型检查及现有 9 项回归测试通过。示例预览不连接 LCU。

可运行 `node packages/desktop/scripts/preview-ui.cjs` 后访问 `/showcase?theme=dark&phase=live` 或 `/showcase?theme=light`，在 1280 × 900 的完整窗口预览中复查效果。

## 后续修正

- 原生 `select` 的系统弹出菜单通过 `color-scheme` 随浅色、深色及系统主题更新；`option` / `optgroup` 使用不透明的主题底色，避免浅底白字。覆盖符文配置、出装方案与英雄排名筛选器。
- 技能优先级三个标签统一为 56 × 60px，字级和内边距一致。
- 普通模式与迷你模式使用 **220ms 的 View Transition 快照交叉淡入淡出**。先捕获已经包含壁纸与磨砂的完整页面，再动画化旧、新页面的快照。真实卡片及其祖先始终保持 `opacity: 1`，避免原先整页淡化时形成背景滤镜采样边界的问题；保留局部文字动画。
- 路由守卫等待旧画面捕获后再提交导航，等待 Vue 更新后才捕获新画面。快速导航会跳过上一次过渡；导航取消或失败会释放快照；首次加载、同模块查询参数变化、系统开启“减少动态效果”以及不支持 API 的环境直接更新页面。
- 示例预览可增加 `motion-audit=1`，通过真实导航点击连续采样 45 帧，结果写入隐藏的 `#motion-audit` 元素。浅色、深色各采集到 37 帧正在进行的快照淡入淡出，卡片滤镜及祖先透明度均无异常。生产应用不包含此检查代码。
- `node packages/desktop/scripts/check-route-transitions.cjs` 的 5 项真实 Vue Router 集成检查覆盖正常提交、快速切换、导航失败、减少动态效果、API 缺失及启动异常；与既有 9 项数据检查均通过，Web 类型检查和桌面构建也已通过。

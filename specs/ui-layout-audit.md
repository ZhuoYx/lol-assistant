# 全局样式与响应式检查

本次检查覆盖首页、战绩列表与详情、英雄统计、符文出装、选人助手、英雄排名、设置，并同步了引导页和迷你布局的基础面板样式。

## 结论与调整

主要页面原来已经使用半透明背景和模糊，但面板样式、页头、圆角和阴影分散在各组件。多个响应式断点只判断窗口宽度，未计算侧栏占用的空间。

- 新增 `PageHeader.vue`，统一标题、副标题、操作区和页头间距。首页、战绩和英雄统计补齐页头，四个攻略模块的数据源选择统一放在操作区。
- `global.css` 的 `.card` / `.glass-panel` / `.glass-surface` 共用半透明背景、20px 圆角、边缘高光、细颗粒纹理和磨砂。2026-10-30 将默认透明度调为 60%、模糊调为 28px，并提供设置项，详见 `glass-material.md`。
- 主内容区使用 `workspace` 尺寸容器，分栏依据实际内容宽度调整。侧栏收起后可立即利用新增空间。
- 技能加点表移除逐单元格模糊，仅保留外层面板的玻璃效果，减少重复滤镜层。
- 表格保持列的可读宽度，通过局部滚动访问完整数据。滚动区域可用键盘聚焦，战绩详情提供滚动提示。
- 深色模式增加 `--color-on-accent`，修正符文应用按钮、英雄排序按钮等主色控件的文字对比度。

## 渲染验证

使用独立的示例数据预览，不连接 LCU，不修改客户端设置。预览调用真实构建产物及实际页面组件，验证布局和样式。

- 1024px 窗口：内容区约 747px；英雄统计、符文出装、双方阵容为单列。
- 1280px 窗口：内容区约 990px；英雄统计、符文出装、双方阵容恢复双列。
- 1440px 窗口：内容区约 1150px；概览三列，主要内容保持双列。
- 1024px 窗口收起侧栏：内容区增至约 903px，符文出装由单列恢复双列。
- 已检查深色、浅色模式、长昵称、长英雄名、真实尺寸图标、20 条战绩及 10 人详情。
- 以上有数据的页面未发现整页横向溢出；所检查的主面板均应用了模糊。窄窗口下排名表和战绩详情的局部滚动符合预期。

DOM 测量结果可在预览的检查栏中实时查看。其中 `invalid` 为溢出候选列表，含头像等级徽章、段位发光和隐藏工具提示等有意超出自身盒子的元素；`pageOverflow` 记录实际页面溢出情况。临时截图及测量记录不纳入版本控制。

运行预览：

```powershell
pnpm build:desktop
node packages/desktop/scripts/preview-ui.cjs
```

打开 `http://127.0.0.1:5179/audit?w=1024&theme=dark`，可调整 `w`、`theme`；加 `phase=draft` 或 `phase=live` 检查相应阶段。直接打开根路径可查看无检查栏的完整页面。
